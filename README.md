# Регистратура онлайн

Курсовой проект: десктоп-приложение для электронной записи пациентов на приём к врачу и вызова врача на дом.

Приложение моделирует работу регистратуры медицинского учреждения: пользователь заводит личный кабинет, заполняет свои данные (СНИЛС, полис ОМС, контакты), в несколько шагов выбирает регион, больницу, специализацию, врача и удобное время, получает талон на приём, который можно распечатать или сохранить в файл. Также доступна возможность оставить заявку на вызов врача на дом — для себя или для другого человека.

## Возможности

- **Регистрация и авторизация** — создание аккаунта с валидацией логина, e-mail и пароля, вход в личный кабинет, показ/скрытие пароля.
- **Личный кабинет** — хранение и редактирование персональных данных: ФИО, СНИЛС, дата рождения, пол, адрес.
- **Запись на приём к врачу** — пошаговый мастер из пяти шагов:
  1. выбор региона (области),
  2. выбор больницы,
  3. выбор специализации,
  4. выбор врача и времени из расписания на неделю,
  5. подтверждение записи и генерация талона.
- **Вызов врача на дом** — заполнение данных пациента (себя или другого человека), номера полиса ОМС, телефона, адреса и симптомов; сохранение заявки в базе данных.
- **Записи и обращения** — просмотр своих талонов и вызовов, повторная печать или сохранение талона в файл.
- **Поиск и фильтрация** — живой поиск на каждом шаге записи (регион, больница, специализация, врач).
- **Печать талона** — генерация документа талона через системный диалог печати.
- **Сохранение талона** — экспорт талона в текстовый файл (.txt).
- **Сквозные проверки ввода** — маски для СНИЛС (`XXX-XXX-XXX XX`), телефона (`+7 (XXX) XXX-XX-XX`) и номера полиса ОМС (16 цифр).

## Модель данных

| Таблица | Описание |
|---|---|
| `Users` | учётные записи и персональные данные пациентов |
| `Regions` | области/регионы |
| `Hospitals` | больницы (привязка к региону) |
| `Specializations` | специализации (привязка к больнице) |
| `Doctors` | врачи (привязка к специализации, расписание) |
| `Tickets` | талоны на приём |
| `Calls` | заявки на вызов врача на дом |

База данных находится в файле `CourseWork2/db/users.db` и подключается через строку подключения `DefaultConnection` в `App.config`.

## Сборка и запуск

1. Установите Visual Studio (2017 и новее) с компонентом «.NET desktop development».
2. Убедитесь, что установлен **.NET Framework 4.8.1** Developer Pack.
3. Откройте `CourseWork2.sln` и дождитесь восстановления NuGet-пакетов (EntityFramework, MaterialDesignThemes, System.Data.SQLite и др.).
4. Соберите решение (Build → Build Solution) и запустите.

Новая база данных создаётся автоматически при первом запуске, а для её использования потребуется SQLite Data Provider, который подключается пакетами автоматически.

## Сценарии использования

1. **Регистрация** — создайте аккаунт и войдите в систему.
2. **Личный кабинет** — заполните ФИО, СНИЛС, дату рождения, пол и адрес (обязательно для записи).
3. **Запись на приём** — пройдите шаги «Регион → Больница → Специализация → Врач и время», подтвердите запись и распечатайте/сохраните талон.
4. **Вызов врача на дом** — укажите, для кого вызов (себя или другого), введите полис ОМС, телефон, адрес и симптомы — заявка сохранится в разделе «Записи и обращения».
